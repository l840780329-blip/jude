# 李昊哲 · 个人作品集

React + Vite 单页网站。PC 版心最大 1700px，同时兼容手机和平板。

## 本地运行

```bash
pnpm install
pnpm dev
```

也可使用 `npm install` 和 `npm run dev`。

## 构建

```bash
pnpm build
pnpm preview
```
